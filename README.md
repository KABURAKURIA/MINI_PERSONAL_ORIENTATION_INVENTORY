# Mini Personal Orientation Inventory (POI) Assessment Tool

An interactive psychometrics assessment, scoring, and visualization platform based on Everett Shostrom's **Personal Orientation Inventory (POI)**—a foundational instrument for measuring self-actualization, values, and psychological autonomy.

---

## Assessment Dimensions

The Mini-POI evaluates core constructs associated with healthy psychological functioning:

1. **Time Competence (Tc)**: Measures the degree to which an individual lives primarily in the present rather than with excessive regret over the past or anxious anticipation of the future.
2. **Inner Directedness (I)**: Measures whether an individual acts according to internal standards and autonomous motivations rather than conforming solely to external societal pressures.
3. **Sub-Scales & Value Profiles**:
   - Self-Actualizing Value (SAV)
   - Existentiality (Ex)
   - Feeling Reactivity (Fr)
   - Spontaneity (S)
   - Self-Regard (Sr) & Self-Acceptance (Sa)

---

## Application Features

- **Interactive Glassmorphic Assessment Form**: Responsive Likert assessment interface styled with modern CSS.
- **Real-Time Score Normalization**: Algorithmic scoring with percentile norm calculations against standard population baselines.
- **Interactive Altair Visualizations**: Radar profiles and bar charts depicting psychological dimension balances.
- **Automated PDF Assessment Reports**: Generates downloadable PDF summaries with dimensional scores and interpretations.
